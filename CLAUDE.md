# CLAUDE.md — Create+Everyday Shopify Theme

Project context for Claude Code. Read this before touching anything in `theme/`.

## The business

- **Brand:** Create+Everyday (storefront also branded **TwiZzyPrintz / TwiZzyPrintzStudio**)
- **Domain:** createeveryday.art
- **Plan:** "Pause and Build" — the storefront is reachable but checkout is limited. Treat the live theme as **publicly visible**.
- **Today's catalog:** an art / print-on-demand shop — stickers, posters, apparel, "t-moji", animation art, wildlife, robots. Fulfilled in part via the **Yoycol** print-on-demand app.
- **Where we're going:** reposition the storefront to feel **high-end, cinematic, 3D, and automotive-focused**. This is a brand/visual pivot, not just a CSS tweak — see `AUDIT.md`.

## The theme

- **Base theme:** **Spotlight v12.0.0 by Shopify** (a free, Online Store 2.0 theme in the Dawn family). themeStoreId `1891`.
- **Architecture:** Online Store 2.0 — JSON templates (`templates/*.json`), sections-everywhere, blocks, and section groups (`header-group.json`, `footer-group.json`). The homepage is fully modular via `templates/index.json`.
- **CSS/JS:** Vanilla. No build step, no framework, no Tailwind/SCSS. Plain `.css` files and web-component-based vanilla JS (`global.js`, etc.) loaded per-section. Spotlight's signature look uses organic "blob" image masks (`assets/mask-blobs.css`).
- **Fonts:** Montserrat (headings `montserrat_n7`, body `montserrat_n4`) via Shopify font picker.
- **Palette (current live):** dark — black backgrounds (`#000000`), white text, red/orange accents (`#b90000`, `#ff5f00`). Already a strong base for an automotive/cinematic direction.

## How this repo was created

There is no Shopify CLI auth in this environment, so the theme was pulled from the
live (MAIN) theme via the **Shopify Admin API** (GraphQL `theme.files`) and mirrored
into `theme/`. The mirror contains all source (liquid / json / css / js). It omits
non-English translation files and binary assets (e.g. `assets/sparkle.gif`) — pull
those on demand if needed.

## Working rules (IMPORTANT)

1. **Never edit the MAIN/live theme.** All work goes to the **SAFE BUILD** unpublished
   theme, previewed, approved, then published deliberately. The Admin API also *blocks*
   theme-file writes to the live theme — another reason to use SAFE BUILD.
2. **Prefer adding new section files** over modifying Spotlight core files. New sections
   are opt-in (only render when added to a template) and can't break existing pages.
3. **Don't touch `config/settings_data.json` by hand** — it's auto-generated by the theme
   editor. Change settings in the editor, then re-pull.
4. **Keep changes mergeable with Spotlight.** Avoid rewriting `base.css`, `global.js`,
   `main-product.liquid`, etc. Add scoped CSS/JS in your own section's `{% stylesheet %}`/
   `{% javascript %}` or new asset files.
5. **Accessibility & performance:** match Spotlight conventions — lazy-load images,
   `prefers-reduced-motion` guards, responsive `srcset`, semantic headings.
6. The audit phase is **read-only**. Do not make design changes until the plan in
   `AUDIT.md` is approved.

## Map (what controls what)

- **Homepage:** `templates/index.json` (the section stack + all content/settings).
- **Global wrapper / `<head>` / scripts:** `layout/theme.liquid`.
- **Header & footer:** `sections/header.liquid` + `header-group.json`; `sections/footer.liquid` + `footer-group.json`.
- **Product cards:** `snippets/card-product.liquid` + `assets/component-card.css` (driven by `settings.card_*`).
- **Product page:** `sections/main-product.liquid` (94 KB) + `assets/section-main-product.css`.
- **Theme tokens (colors/spacing/radius):** generated in `layout/theme.liquid` from `config/settings_data.json` → CSS custom properties consumed by `assets/base.css`.

See `AUDIT.md` for the full structure, edit/no-touch lists, risks, and build plan.
